司法書士 一問一答○×アプリ v001

■構成
- index.html：アプリ本体
- manifest.webmanifest / sw.js：PWA設定
- data/items.csv：肢別問題データ

■今回の収録範囲
- 令和7年度・令和8年度
- 午後の部
- 不動産登記法・商業登記法
- answer_as_of_exam が ○ または × の肢のみ
- 収録件数：200肢

■操作
1. 科目・年度・出題方法を選択
2. 学習開始
3. 肢を読んで○または×を押す
4. 正誤だけを表示し、約0.5秒後に自動で次へ進む
5. 間違えた肢・お気に入りは端末内に保存

■正誤データの注意
正誤は、各問題の正解番号（令和8年度は公式解答、令和7年度は利用者提供の予備校解答）から組合せ肢を展開したものです。
肢ごとの条文・判例等による独立した法的根拠確認、現行法との照合、全行の目視校正は未完了です。
そのため、画面では解説を省いていますが、正誤自体が完全検証済みという意味ではありません。
未確定の40行は今回の出題データから除外しています。

■GitHub Pagesへの設置
既存の択一アプリとは別のリポジトリを作るのが安全です。
ZIPを展開し、index.html / manifest.webmanifest / sw.js / data フォルダをリポジトリ直下にアップロードしてCommitしてください。
GitHub Pagesを有効にすると別URLのアプリとして使えます。
